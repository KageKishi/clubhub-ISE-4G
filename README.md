# ISE · ITC Club Hub
ITC Club Hub · clubhub-ISE-4G (v0.1.0)

ITC Club Hub is a software engineering platform for students at the Institute of Technology of Cambodia (ITC) to discover student clubs, manage memberships, and participate in campus activities.
